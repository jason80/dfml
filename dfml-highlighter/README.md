# Dragonfly Markup Language (DFML) Syntax Highlighter

[![VS Code Marketplace](https://img.shields.io/badge/VS%20Code-Marketplace-blue)](https://marketplace.visualstudio.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Syntax highlighting support for Dragonfly Markup Language (DFML) in Visual Studio Code.

## Features

- Full syntax highlighting for DFML files
- Support for:
  - Node declarations with attributes
  - Strings
  - Numbers and booleans
  - Comments (`//`, `#`, `/* */`)

## Instalation

### Manual Installation

1. Download the `.vsix` file
2. Open VS Code
3. Go to Extensions (Ctrl+Shift+X)
4. Click on the "..." menu and select "Install from VSIX"
5. Select the downloaded file

### Development Installation

1. Clone the repository:
```bash
git clone https://github.com/jason80/dfml
```

## File Associations

The extension automatically associates the following file extensions with DFML:

- `.dfml`
